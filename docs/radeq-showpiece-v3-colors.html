Color-mody i tvary jsou bounded enumy z brand-tokenů (zde demo-palety HAND teplá / MACHINE ink+lime). Canvas2D, 0 závislostí, adaptivní throttle (HUD = reálné body). Tvoje reálné radeq.cz jede na Three.js + heroCatPoints (faithful sampling z kocka_body.png — stejná DNA jako autopilot image-point-cloud); WebGL-only mody (true iridescent/glow) jsou tam zdarma, klientům jde gated Canvas2D podmnožina.
